# FieldScope Lab · 本地字段范围采集演练台

一个完全本地运行的演练系统：模拟数据来源按用途签发字段范围，接收端分块下载并逐块校验，
索引按当前授权发布，查询与导出在每次请求时重新校验字段。所有客户数据均为虚构，
来源、接收、索引、页面与测试都不访问外部网络。

## 运行

```bash
npm start            # http://127.0.0.1:4173
npm test             # 32 个 Node 测试（授权、传输、竞态、索引、导出、完整性）
npm run test:ui      # jsdom 驱动真实页面 + HTTP 服务的端到端场景
```

可选环境变量：`PORT`、`FIELDSCOPE_DB`（SQLite 路径）、`CHUNK_LATENCY_MS`（模拟下载延迟）。
运行依赖只有 Node ≥ 22.5（使用内置 `node:sqlite`）；`jsdom` 仅用于端到端页面测试。

## 页面能做什么

- 顶部切换三个用途：账单核对（billing）、用量分析（analytics）、客户关怀（care）。
  每个用途有独立的授权字段集合、版本号与逐字段授权纪元（epoch）。
- 勾选/取消字段后点“应用字段范围”。撤出的字段会立即从块、索引与导出副本中清除，
  并写入只含字段名与计数的不可逆墓碑；页面会先确认再执行。
- “开始采集”按 6 个块逐块下载；可勾选“模拟断线”在第 N 块后断开，再点“从断点恢复采集”。
  面板逐块显示 `已校验 / 复用 / 缺列 / 已清除 / 已丢弃`，并解释每块复用或重取的原因。
- “构建并发布索引”会复核每个块、任务范围与当前授权，再用比较并交换发布。
- 查询和导出只作用于当前授权字段；“最终检查”显示授权、索引一致性、块覆盖、
  查询是否过期与撤权墓碑。

## 关键规则

### 块可复用，当且仅当

1. 块完整接收，字节长度与内容哈希校验通过；半包字节直接丢弃，不做跨版本拼接。
2. 块内每一列仍属当前用途授权，且该列纪元与当前一致。
3. 块覆盖当前授权的全部字段；缺列（撤权后又重新授权）只能整块重取。
4. 数据集修订号与来源当前修订号一致。
5. 落盘内容再次读回校验：行宽与字段集合一致、`rows_hash` 未变化。损坏块在预判阶段即改为下载。

任何一条不满足都会整块重取，并在页面与任务详情中给出具体原因（`E_CHUNK_MISSING_FIELD`、
`E_CHUNK_EPOCH`、`E_CHUNK_REVISION`、`E_CHUNK_HAS_REVOKED`、`E_CHUNK_CORRUPT` 等）。

### 可发布，当且仅当

1. 六个块全部通过上述复用校验；缺块、缺列或纪元过期的块使构建直接失败。
2. 构建前后各做一次授权复核；提交事务内再次比较并交换授权签名。
3. 若指定任务，任务必须已完成、用途一致、字段集合完全一致，且栅栏不超前。
4. 发布成功后旧活动索引变为 `superseded`；构建失败不会覆盖仍可用的旧索引。

查询与导出每次按当前授权重新校验：请求越权字段直接拒绝（403）。索引与当前授权不一致时，
查询会把过期或缺列的字段遮蔽、绝不返回原值；导出要求索引完整覆盖当前授权，否则拒绝（409）。
撤权清理在同一事务内完成，索引副本中的被撤列被实际删除；若剩余列仍覆盖当前授权，
索引可以继续服务，若之后重新授权了新列，缺列会让索引过期并阻止导出。

### 授权缩小 / 竞态

- 撤权入口只有一个（`AuthzStore.setFields`），撤权副作用通过钩子在该入口内同步执行：
  清块、清索引、写墓碑、写审计。任何调用方都无法绕过清理。
- 下载中途撤权：来源在下载时复核字段，接收端丢弃本次字节，任务标记 `invalidated`，
  并把该用途所有已落盘副本中的被撤列一并清除。
- 索引构建中撤权：提交前复核失败，构建标记 `aborted`；事务内比较并交换失败标记
  `E_CAS_FAILED`。两者都不会发布旧范围。
- 旧任务晚完成：任务范围签名与当前授权不一致时不能用于发布（`E_JOB_SCOPE_STALE`），
  且其下载的块会在下一次复用判定中因缺列/纪元变化被整块重取。
- 两个用途同时采集同一数据集：块、索引、栅栏、任务全部按用途隔离，互不扩大范围。

### 失败详情不泄露原值

错误详情只包含错误码、块号、字段名与计数；行数据、令牌与遮蔽前的值一律不进入错误、
任务详情、审计或墓碑。测试逐项断言敏感原值不会出现在这些位置。

## 目录

```
src/config.js             虚构数据集、字段敏感度、用途与策略文案
src/db.js                 SQLite 表结构与迁移
src/crypto.js             指纹与遮蔽值（不可逆）
src/app.js                服务装配、状态聚合、错误到 HTTP 的映射
src/server.js             本地 HTTP 服务与静态文件
src/services/authz.js     用途授权、字段纪元、范围签名、撤权钩子
src/services/source.js    模拟来源：令牌签发、分块下载、故障注入
src/services/receiver.js  分块接收：哈希/结构/字段/行宽校验
src/services/chunkScope.js 块复用判定的唯一入口
src/services/collector.js 任务、预判、断线恢复、撤权清理、墓碑
src/services/indexer.js   索引构建、比较并交换发布、查询复核、撤权清理
src/services/exporter.js  导出前字段与索引一致性校验
web/                      页面（无框架，原生 DOM）
test/                     Node 测试与 jsdom 端到端脚本
```
